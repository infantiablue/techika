# Methodology and source register

## Collection

The research used primary browser documentation retrieved directly on 2026-08-29. Source pages were fetched with HTTP redirect following and failure status enabled. The article uses MDN for browser API semantics.

## Scope boundary

The sources establish browser API behavior. They do not establish that an individual deployment will work through every proxy, CDN, corporate network, authentication scheme, or rate limit. Those are implementation-specific facts and require environment testing.
